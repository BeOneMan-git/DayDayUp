# DayDayUp 安装与更新说明（V1.0 稳定自用）

这份说明带你把 DayDayUp 装到 iPad 上，并且每周更新。整个过程分四部分：装电脑端工具、装 App、导入内容包、每 7 天重装一次。前两部分只做一次。App 怎么用，见 [GUIDE.md](GUIDE.md)（App 里“设置 › 关于与使用说明 › 使用说明”是同样的内容）。

**从 V0.2 升级到 V1.0 的人，先看下面的“升级到 V1.0”。**

- 电脑：Windows 电脑
- iPad：iPad Pro 12.9 英寸（第三代），iPadOS 26.x
- 账号：一个专门用来签名的 Apple ID（不用你的主账号）
- 一根能传数据的 USB 线

> 为什么要这样装：DayDayUp 不上架 App Store，只给你自己用。免费 Apple ID 可以给自己装的 App 签名，但签名只管 7 天，所以每周要重装一次。重装是覆盖安装，学习记录都在。

## 升级到 V1.0（从 V0.2 升级，只做一次）

V1.0 改了学习记录和内容包的格式。升级本身不删数据，但先备份最稳妥。按顺序做：

1. **装新版前，先做完整备份。** 在旧版 App 里：设置 → 数据与备份 → 立即完整备份，存到“文件”App 的“我的 iPad”或 iCloud 云盘。
2. **按第三步安装 V1.0。** 覆盖安装，不要先删除旧 App。
3. **第一次打开。** App 自动把旧“生词本”转成词汇页里的词项，只转一次。“今日”会排出“建立基线”。
4. **导入 6 个新格式内容包（格式 2）。** 文件在电脑上的“内容包（格式2）”文件夹里，一共 6 个 `.ecopack`。用第四步的方法 A 放进 iPad，打开 App 后，书架顶上会出现“在 App 文件夹里发现 6 个内容包 → 查看并导入”。点开预览：每个包应显示“新版本”，正文句子没有变化，新增“发音标注”和“理解题”。确认后点“导入所选”。
5. **检查。** 书架里文章都在；旧的听读进度还在；理解题按钮能用（书架长按文章 → 做理解题）。
6. **再做一次完整备份。** 设置 › 备份与恢复 › 立即完整备份。这份是 V1.0 格式的第一份备份。

> 如果升级后发现问题，可以用“设置 › 备份与恢复 › 从备份恢复”选第 1 步的备份。恢复前的数据会自动留一份，恢复后还能点“撤销这次恢复”。

## 第一步：在 Windows 上装 iTunes、iCloud 和 AltServer（只做一次）

1. 如果电脑上装过“微软商店”版的 iTunes 或 iCloud，先卸载。AltServer 只认苹果官网的版本。
2. 从苹果官网下载并安装 iTunes（64 位）和 iCloud。下载链接在 AltStore 的官方说明里：
   <https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows>
3. 在同一个页面下载 AltServer（altinstaller.zip），解压后运行 Setup.exe。
4. 用管理员身份运行 AltServer。它只在任务栏右下角显示一个小图标（在 ^ 里面）。
5. 用数据线连好 iPad，iPad 保持解锁，点“信任此电脑”。
6. iTunes → 点 iPad 图标 → 勾“通过 Wi-Fi 与此 iPad 同步”，取消“连接时自动同步”，点“应用”。

## 第二步：iPad 上的设置（只做一次）

1. 第一次装好 App 以后，打开 **设置 → 通用 → VPN 与设备管理**，点你的签名 Apple ID，再点“信任”。这一步要联网。
2. 打开 **设置 → 隐私与安全性 → 开发者模式**，打开开关。iPad 会重启，重启后再点一次“打开”。

## 第三步：安装或更新 DayDayUp

1. 从 GitHub 仓库的 Releases 页面下载最新的 `DayDayUp.ipa`。
2. 把它放到**英文路径**，例如 `C:\Users\你的用户名\Downloads\DayDayUp.ipa`。路径里有中文时，AltServer 会报 “The app could not be found”（错误 1005）。
3. 按住 **Shift**，点任务栏右下角的 AltServer 图标，选 **Sideload .ipa**，再选你的 iPad。
4. 选第 2 步的 ipa，输入签名专用 Apple ID，等安装完成。
5. 如果这一版会改数据格式（发布说明里会写），安装前先在 App 里做一次完整备份。

> 如果 AltStore 里能正常登录，也可以在 AltStore → My Apps → “+” 里装，AltStore 会在后台自动续签。现在这台电脑上 AltStore 登录不成功，所以用上面的方法。

## 第四步：导入内容包

内容包是 `.ecopack` 文件，一个文件装一期（或半期）的文章、音频和词卡。

- **方法 A（推荐，已实测）：iTunes 文件共享。** iTunes → 点 iPad 图标 → 文件共享 → DayDayUp → 添加文件… → 选 `.ecopack`。对话框里可以直接粘贴中文路径。然后在 iPad 上打开 DayDayUp（已经开着就回到主屏幕再点开）。书架和设置顶上会出现“在 App 文件夹里发现 n 个内容包 → 查看并导入”。
- **方法 B：在 App 里选。** DayDayUp → 书架 → 右上角“导入内容包” → 选文件（可以多选）。

两种方法都会先显示**导入预览**，你确认以后才写入书架：
- 新增：书架里还没有这一期。
- 已导入：同一个文件导入过，不会重复导入。
- 冲突：版本号一样，但内容不同。默认保留现在的；也可以选“替换”或“另存副本”（文件放到 我的 iPad › DayDayUp › 冲突副本，不导入）。
- 新版本：列出新增、删除、修改的文章和句子；无法对应的旧句子，学习记录保留，不会挂到新句子上。
- 空间：文件 ≥100 MB 时提醒；剩余空间不够时不导入，原来的书架照常可用。

导入成功的文件会移到“文件”App 的 **我的 iPad › DayDayUp › 已导入**。确认书架里文章都在以后，可以删掉它们省空间。

## 每周六例行（约 20 分钟）

1. 电脑上按第三步重装一次。这一步同时完成 7 天续签；有新版时装的就是新版。
2. 用 iTunes 文件共享放入本周的内容包，打开 App，在导入预览里确认。
3. 在 App 里 **设置 › 备份与恢复 › 立即完整备份**，存到“文件”App 或 iCloud 云盘。

- 签名过期以后，图标还在但打不开。**不要删除 App**，删除会清掉内容包、学习记录和录音。重装一次就好。
- 重装要用同一个 Apple ID。换账号签名，iPad 会把它当成另一个 App。
- 免费账号同时最多 3 个自签 App（AltStore 占 1 个）。

## V1.0 能做什么

详细用法见 [GUIDE.md](GUIDE.md)。这里只列大块：

- **今日计划**：每天 60 / 90 分钟（可自定义 30–120），分词汇、听读、跟读、说写四类任务，每项写明“为什么推荐”；可以开始、换一篇、暂缓；做完自动打勾，不重复计数。第一次使用先做“首次基线”（4 个小任务，只给描述，不给雅思分）。
- **听读**：逐词高亮、盲听、循环、变速、中文、点词看词卡、收藏义项和词群、理解题、个人难度、专注模式。英文正文默认 24 pt，可调 18–34 pt。
- **跟读**：听后跟读、影子跟读、看稿朗读、脱稿复述四种模式，A/B 对比，发音标注（待核对）。
- **词汇**：FSRS 排期，六种题型，积压时自动停新词。
- **雅思说写**：基础训练和考试题型（Part 2、完整模拟、Task 1、Task 2），题目全部原创；有反馈或重写后，3–7 天安排同类新题复测。
- **进度与周报**：投入（有效练习时间）和证据（回忆、理解题、录音、作品、问题复发）分开看；样本少会明说。每周一准备上周周报，可导出 JSON、CSV、PDF。
- **书架**：刊期 / 主题切换、搜索、筛选（难度、可离线、待校准、未完成、已收藏），四类进度。
- **备份与恢复**：完整备份导出前列明内容；恢复先在临时库演练，列出记录数和缺失的内容包 / 录音，确认后才切换，可撤销。
- **录音清理**：不会自动删除；清理前先预览，保留首次、最近 3 次、复测、作品相关的录音；只删文件，不删记录。
- **隐私**：App 没有任何联网代码，不上传。文件只在你导出或分享时离开 iPad。
- **诊断日志**：设置 › 关于与使用说明 › 导出诊断日志。文件在“文件”App 的 我的 iPad › DayDayUp › 诊断，也能用 iTunes 文件共享取到电脑上。

## 14 天试用：请重点看这些

1. 每天从“今日”开始，按计划做完一轮；看“为什么推荐”说得对不对，自动打勾准不准。
2. 首次基线分 2–3 次做完；看建议阶段是否合理。
3. 听读：换不同字号、横竖屏、分屏各用一次；在窄窗口里点词，单词卡应从底部弹出。
4. 隔天做一次“隔日回忆”，每周做一次“新材料复测”。
5. 第 7 天：重装续签（第三步），看数据是否都在；做一次完整备份。
6. 第 8–14 天：用备份做一次“从备份恢复”演练，再点“撤销这次恢复”。
7. 发现问题时：记下时间和页面，导出诊断日志，一起发给我。

## 常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| AltServer 报 The app could not be found（1005） | ipa 所在路径有中文 | 把 ipa 复制到英文路径再装 |
| AltStore 里登录提示 Apple ID 或密码不正确 | 原因未查清：账号输错，或代理软件影响 | 先用第三步的 Shift + Sideload 方法 |
| 打开 App 提示“不受信任的开发者” | 还没信任签名账号 | 设置 → 通用 → VPN 与设备管理 → 信任 |
| 点图标没反应，或提示 App 已不可用 | 7 天签名到期 | 按第三步重装；不要删除 App |
| 跟读页说麦克风权限已关闭 | 第一次问时点了“不允许” | 设置 → 隐私与安全性 → 麦克风 → 打开 DayDayUp |
| 录音只保存了一部分，标着“被打断” | 录音时来电话、叫了 Siri，或切出了 App | 正常现象，录音已保存；需要的话再录一次 |
| 导入预览列出“校验失败”或“缺文件” | 文件没拷完整或已损坏 | 重新拷一次这个 `.ecopack`；原来的书架不受影响 |
| 书架里一期只有一半文章 | 那一期的另一个文件还没导入 | 把同一期的两个文件都导入 |
| 放进去的内容包没有出现在书架 | V1.0 不再静默导入 | 打开书架，点顶上的“查看并导入”，在预览里确认 |
| 导入预览显示“冲突” | 版本号一样，但文件内容不同 | 默认保留现在的；确实要换，选“替换” |
| 恢复以后想回到恢复前 | 恢复前的数据自动留了一份 | 设置 › 备份与恢复 › 从备份恢复 → 撤销这次恢复 |
| 回放时显示“录音已清理” | 那条录音的文件已在“录音清理”里删掉 | 记录还在；需要的话重新录一次 |

## 这个仓库里有什么

- `DayDayUp/`：App 源代码（SwiftUI，iPadOS 26 起）。
- `project.yml`：XcodeGen 配置。GitHub 的 macOS 机器用它生成 Xcode 工程，所以不需要自己的 Mac。
- `.github/workflows/build.yml`：推送到 dev 分支只编译和跑逻辑测试；推送到 main 分支才产出未签名的 DayDayUp.ipa，发布到 Releases。安装时用你的 Apple ID 签名。
- `.github/workflows/test.yml`：在同一类 macOS 机器上，用 iPad 模拟器再跑一遍逻辑测试，并为模拟器编译 App。不产出 ipa，失败也不会挡住上面的安装包。怎么开、能测什么，见 [TESTING.md](TESTING.md)。
- `LogicTests/`：纯逻辑的测试（FSRS 排期、队列、计划、统计、答案核对、内容包比对等），在 CI 里运行。
- `docs/GUIDE.md`：使用说明。
- 仓库里没有任何杂志内容。内容包只放在你的电脑和 iPad 上，只供个人学习。雅思题目和参考答案是原创的。
