# DayDayUp

自用的 iPad 英语学习 App：边听边读英文长文章，点词看详解卡，跟读、说、写都在本机完成，按雅思要求练。

**V0.2 说写起步**（当前）：

- 书架与听读：按期导入内容包（`.ecopack`）；逐词高亮跟随朗读；点词看释义卡；句子解析；盲听；单句循环、A–B 循环、循环间隔；0.5–1.5× 变速不变调；逐段展开译文；报错；锁屏和耳机控制。
- 跟读（听后模仿）：一次一句，听原句 → 录音 → A/B 对照，每次录音都保存。
- 雅思基础说写：口语准备 30 秒、说 45 秒；写作 5–10 分钟、3–5 句；先四维自评再看参考；原稿只读，改写成新版本；手动录入老师或 Claude 的反馈。题目和参考答案为原创。
- 词汇：生词本和认识的词。
- 数据：学习记录和录音只存在本机；完整备份（`.ddubackup`）含录音和作品；诊断日志可导出。

后续版本：V0.3 词汇记忆（FSRS）、V0.4 跟读与考试题型、V0.5 今日计划与进展、V1.0 稳定自用。

安装方法见 [docs/INSTALL.md](docs/INSTALL.md)。

本仓库只有代码和原创题目，不含任何杂志内容。
