# DayDayUp

自用的 iPad 英语学习 App：边听边读英文长文章，点词看详解卡，按雅思要求学词。

**V0.1 听读版**（当前）：

- 书架：按期导入内容包（`.ecopack`），显示每篇的“听、读”进度环，可按进度和雅思话题筛选。
- 听读：原生文字，逐词高亮跟随朗读；点词看释义卡（语境义、常用释义、搭配、雅思例句、词根词缀、近义辨析）；句子解析；本文词表。
- 播放：变速不变调、单句循环、逐句暂停、盲听、锁屏和耳机控制、后台播放；键盘快捷键（空格、← →、L）。
- 词汇：生词本和认识的词。
- 数据：学习记录只存在本机，可一键备份和恢复；超过 7 天没备份会提醒。

后续版本：V0.2 词汇复习（FSRS）、V0.3 跟读与评分、V0.4 今日计划与进度看板。

安装方法见 [docs/INSTALL.md](docs/INSTALL.md)。

本仓库只有代码，不含任何杂志内容。
