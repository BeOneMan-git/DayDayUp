# DayDayUp

自用的 iPad 英语学习 App：边听边读英文长文章，点词看详解卡，跟读、说、写都在本机完成，按雅思要求练。

**V1.0 稳定自用**（当前）：

- 今日计划：每天 60 / 90 分钟（可自定义 30–120），词汇、听读、跟读、说写四类任务，每项写明推荐理由；开始、换一篇、暂缓；按记录自动完成，不重复计数。首次使用先做基线（只给描述，不给分数）。
- 书架与听读：按期导入内容包（`.ecopack`，导入前先预览）；逐词高亮跟随朗读；点词看释义卡；收藏义项与词群；盲听、循环、变速；理解题；个人难度；专注模式；英文正文 18–34 pt。
- 跟读：听后跟读、影子跟读、看稿朗读、脱稿复述；A/B 对比；发音标注（待核对）。
- 词汇：FSRS-6 排期（与 py-fsrs 6.3.2 逐次一致），六种题型，积压时停新词。
- 雅思说写：基础训练和考试题型（Part 2、完整模拟、Task 1、Task 2），题目为原创；反馈或重写后安排新题复测。
- 进度与周报：投入和证据分开；样本少时明说；周报导出 JSON / CSV / PDF。
- 数据：学习记录和录音只存在本机，App 没有联网代码；完整备份含录音和作品；恢复先在临时库演练，可撤销；录音清理先预览。

安装与升级见 [docs/INSTALL.md](docs/INSTALL.md)，测试见 [docs/TESTING.md](docs/TESTING.md)，使用说明见 [docs/GUIDE.md](docs/GUIDE.md)。
